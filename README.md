# EGPWS SIMON

航空機の対地接近警報装置（EGPWS）の音声をハックし、AtomS3RとアナログスイッチICで制御可能にした、ハードウェア・ハック・サイモンゲームです。

## 概要

市販の「EGPWS音声キーホルダー」の内部基板を解析・改造し、M5Stack AtomS3Rから制御することで、航空機のアラート音声（PULL UP, SINK RATE, TERRAIN, WINDSHEAR）を順番に記憶してボタンを押していく記憶ゲームです。

単なるプログラム上のゲームではなく、**既存の電子玩具をアナログスイッチIC（HCT4066）でハックし、外部から電気的に「ボタン押し」を再現している**点が最大の特徴です。

※配線図やガジェット内部の改造箇所など、詳細な作り方については [`images` ディレクトリ](./images) 内の画像をご参照ください。

## 主な機能

- **EGPWSサウンドハック:** 4種のアラート音声をランダムなシーケンスで再生。
- **2x2マトリクス制御:** ガジェット側のキーマトリクスを解析し、2本のROW（行）と2本のCOL（列）をHCT4066でクロススイッチング。
- **1ピン・アナログ入力:** 4つの物理ボタンを抵抗分圧（Resistor Ladder）回路で構成し、AtomS3Rの1つのアナログピン（G6）のみで全ボタンを判別。
- **高視認性ステータス表示:** M5Unit GLASS2（モノクロ有機EL）を使用し、入力待機状態を右上のマーカー（●）で表示。
- **航空機演出:** ミス時の「CRASH!!」表示と、3秒間に及ぶ強烈な警告ブザー音による墜落演出。

## ハードウェア構成

- **コントローラー:** M5Stack AtomS3R
- **ディスプレイ:** M5Unit GLASS2 (I2C接続)
- **アナログスイッチIC:** 74HCT4066 (既存ガジェットのボタン制御用)
- **音声ソース:** EGPWS サウンドシミュレーター（キーホルダー改造）
- **入力:** 抵抗分圧式 物理プッシュボタン × 4

### ピンアサイン (AtomS3R)

| ピン番号 | 役割 | 接続先・詳細 |
| :--- | :--- | :--- |
| **G38** | SW1 制御 (1E) | PULL UP (R1-C1 接続) |
| **G39** | SW2 制御 (2E) | SINK RATE (R1-C2 接続) |
| **G7** | SW3 制御 (3E) | TERRAIN (R2-C2 接続) |
| **G8** | SW4 制御 (4E) | WINDSHEAR (R2-C1 接続) |
| **G6** | アナログ入力 | 抵抗分圧式スイッチ読み取り用 |
| **G5** | ブザー出力 | ゲームオーバー/スタート時警告音 |
| **G1/G2** | I2C通信 | M5Unit GLASS2用 |

## 回路解説

### ガジェット基板ハック（キーマトリクス）
ガジェットの基板上の4本の配線を解析し、ROW1, ROW2 / COL1, COL2 として定義しました。HCT4066を用いることで、マイコンからのデジタル信号でこれらの線を物理的に接触させることなく「短絡（スイッチON）」させています。

### 抵抗分圧式入力（デバウンス強化）
限られたピン数を有効活用するため、各ボタンに異なる抵抗値（2.2kΩ、4.7kΩ、10kΩ）を配置し、1つのアナログピンで電圧変化を読み取っています。プログラム側では、ボタンの押し始めと離し際の不安定な電圧（チャタリング）を排除する強固なデバウンス処理を実装し、誤認識を防止しています。
